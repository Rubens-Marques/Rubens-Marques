## 🤖 IA no dia a dia

Uso IA como ferramenta de trabalho real — não apenas como assistente de código:

- **Claude Code** — desenvolvimento assistido por IA em projetos reais de produção
- **RAG (Retrieval-Augmented Generation)** — assistentes que consultam bases de conhecimento internas
- **AI Agents com Tools** — agentes que leem dados, tomam decisões e executam ações via function calling
- **Prompt Engineering** — design de prompts estruturados para outputs consistentes em sistemas de produção
